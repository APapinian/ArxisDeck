## Arxis Deck's own licence

**GPL-3.0-or-later, © 2026 Fatih Bucaklioglu** (decided 2026-11-06, see
`docs/architecture-decisions/ADR-0002-licence.md`). `LICENSE` holds the full text; every source
file has an SPDX line; the Flatpak metainfo sets `project_license`.
Arxis Deck's crates are listed above; it links Qt 6 (LGPL-3.0 for the modules used:
Core, Gui, Qml, Quick) dynamically through the KDE Flatpak runtime, which is compatible with
any licence choice.
