# ADR-0002: Licence and copyright

- **Status:** accepted 2026-11-06 (decided on the owner's behalf, as they asked; they can change it)
- **Date:** 2026-11-06

## Decision

Arxis Deck is licensed under the **GNU General Public License, version 3 or (at your option)
any later version** (SPDX `GPL-3.0-or-later`).

**Copyright:** © 2026 Fatih Bucaklioglu, the owner named in the app ID
(`io.github.APapinian.ArxisDeck`) and the GitHub address (github.com/APapinian, formerly
fatih-bucaklioglu).

## Why

- **It stays free software.** Anyone may use, study, change and share Arxis Deck. Anyone who
  shares a changed copy must share its source under the same terms. That fits a store that
  people trust to install software on their Deck.
- **Same family as Arxis.** The reference project's LICENSE file is GPL-2.0. GPL-3.0-or-later
  stays in that family and adds clearer patent and anti-lock-down terms.
- **Everything used allows it.** All 31 compiled-in crates are MIT, Apache-2.0, Zlib or Unlicense,
  which are compatible with GPL-3.0. Qt 6 (LGPL-3.0) is linked dynamically from the system or the
  KDE runtime. See `docs/research/license-review.md`.
- **No Arxis code is reused.** Only 16 theme colour values and feature ideas came from Arxis.
  So the open questions about Arxis (GPL-2.0 vs MIT, APapinian vs Fatih) do not limit this
  choice. They only matter if Arxis code is copied in later.

## Options considered

| Option | For | Against |
|---|---|---|
| **GPL-3.0-or-later** (chosen) | changed copies stay open; modern terms; compatible with every dependency | closed-source forks are not allowed |
| GPL-2.0-or-later | the same licence family as Arxis | older terms; "or later" lets it move to GPL-3 anyway |
| MIT | simplest; anyone may reuse | others may ship closed copies of the store |

## What changed

- `LICENSE`: the full GPL-3.0 text (identical to gnu.org's `COPYING`, MD5 `1ebbd3e34237af26da5dc08a4e440464`).
- `Cargo.toml`: `license = "GPL-3.0-or-later"`, `authors`.
- An SPDX copyright and licence line at the top of every source file.
- The Flatpak metainfo has `project_license` and `developer`. The package installs `LICENSE`
  and `THIRD-PARTY-LICENSES.md` into `/app/share/licenses/<app id>/`.
- `THIRD-PARTY-LICENSES.md` is generated by `scripts/third_party_licenses.py`.
  `scripts/check.sh` fails if it is out of date.
- About & diagnostics shows the licence and copyright.
